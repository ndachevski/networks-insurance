=== HOW TO RUN THE GAME ===

STEP 1: Compile all Java files
------------------------------
Open PowerShell or Command Prompt in the project directory and run:
    javac -cp ".;lib\*" *.java

If you don't have the lib folder, download the dependencies first:
    powershell -ExecutionPolicy Bypass -File ".\download-junit.ps1"

If you're using VS Code, add this to your settings.json to resolve library dependencies:
    "java.project.referencedLibraries": ["lib/*.jar"]

STEP 1.1: Network Configuration (Optional)
-------------------------------------------
If you want to run this on multiple computers over a network, you'll need to configure the server address.

1. Decide which machine will act as the server.
2. On that machine, open Command Prompt and run: ipconfig
3. Find the IPv4 address (something like 192.168.1.100).
4. On each client machine, open GameClient.java or GameClientGUI.java.
5. Find the line: Server_Host = "localhost"
6. Replace "localhost" with the server's IPv4 address.
7. Recompile: javac -cp ".;lib\*" *.java
8. Now clients can connect to the remote server.

STEP 2: Start the Server
------------------------
Open a terminal window and run:
    java Server

You should see output like:
    Game Server started on port 12345
    Waiting for clients...

STEP 3: Start a Client (Choose One)
------------------------------------

OPTION A: GUI Version (Recommended)
Run either:
    java GameClientGUI

A window will open with:
- Login/Registration screen
- Player list
- Game board interface
- Statistics display

OPTION B: Command Line Version
Run:
    java Client

You'll see:
    === Tic-Tac-Toe Game Client ===
    Type 'help' for commands
    >

STEP 4: Play the Game
---------------------

GUI VERSION:
1. Enter username and password, then click "Register" or "Login"
2. Once logged in, you'll see a list of online players
3. Click "Leaderboard" to see the top players by wins
4. Select a player and click "Challenge Selected Player"
5. When challenged, a dialog appears - click "Yes" to accept
6. A new window opens with the game board
7. Click on any empty cell to make your move
8. The game updates automatically and shows results
9. After a game ends, you can:
   - Click "Request Rematch" to play again with the same opponent
   - Click "Back to Lobby" to return to the player list

COMMAND LINE VERSION:
In a client terminal, try these commands:

1. Register a new account:
   > register alice 1234

2. Login:
   > login alice 1234

3. List online players:
   > list

4. Challenge another player (open another client first):
   > challenge bob

5. Accept a challenge (when challenged):
   > accept

6. Make a move (when in a game):
   > move 0 0
   > move 1 1
   (coordinates are 0-2 for rows and columns)

7. View your stats:
   > stats

8. View the board:
   > board

9. Request a rematch (after a game ends):
   > rematch

10. View leaderboard:
   > leaderboard

11. Logout:
   > logout

12. View all available commands:
   > help

IMPORTANT NOTES:
- Always keep the server running while playing
- You need at least 2 clients to play a game (you and an opponent)
- Start the server BEFORE launching any clients
- To test with 2 players, open 2 separate terminal windows and run "java Client" in each one
- The game board uses coordinates 0-2 for rows and columns

=== RUNNING JUNIT TESTS ===

1. Get JUnit (once):  .\download-junit.ps1

2. Compile:  javac -cp ".;lib\*" *.java

3. Run each test:
   java -cp ".;lib\*" org.junit.runner.JUnitCore ProtocolTest
   java -cp ".;lib\*" org.junit.runner.JUnitCore GameSessionTest
   java -cp ".;lib\*" org.junit.runner.JUnitCore GameServerTest
   java -cp ".;lib\*" org.junit.runner.JUnitCore UserManagerTest

If the IDE can't find org.junit, run the download script then reload the window.
