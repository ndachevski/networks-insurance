=== HOW TO RUN THE GAME ===

STEP 1: Compile all Java files
------------------------------
Open PowerShell or Command Prompt in the project directory and run:
    javac -cp ".;lib\*" *.java
    however if you donnt have the lib folder then you would have to run this commands so that it downloads them : powershell -ExecutionPolicy Bypass -File ".\download-junit.ps1". This would download them into your repository. As well as if you have issues with eror you will have to add this piece of code in the settings.json in your VS code : "java.project.referencedLibraries": ["lib/*.jar"]. With this done then we can procide with the starting of the server.

Step 1.1 This is for information relating wether we will run this application on only 1 computer or on several via a network. Since this projects main goal to run it on a server, we do need to change 3 things. Once we decide which machine is going to be the server hoster we will need to go into that machines ipconfig and see which ipv4 address it has. This address is important since its the one we will be writing it in the GameClient for the CLI version and the GameClientGUI for the GUI version. On both version go to public class GameClient{ or the GameClientGUI{ class.and on the first line we should see Server_Host ="localhost". We will replace the local host with the actual ipv4 adress of the computer which is acting as a server. Then we recomiple everything with the javac -cp ".;lib\*" *.java, and then we can run the command to connect to the server and we can play the match.

STEP 2: Start the Server
-------------------------
In one terminal window, run:
    java Server

You should see:
    Game Server started on port 12345
    Waiting for clients...

STEP 3: Start Client(s) - CHOOSE ONE:
--------------------------------------

OPTION A: GUI Version (Recommended)
    java ClientGUI
    or
    java GameClientGUI
    
    A window will open with:
    - Login/Registration screen
    - Player list
    - Game board interface
    - Statistics display

OPTION B: Command Line Version
    java Client
    
    You'll see:
    === Tic-Tac-Toe Game Client ===
    Type 'help' for commands
    >

STEP 4: Play the Game
---------------------

GUI VERSION:
- Enter username and password, then click "Register" or "Login"
- Once logged in, you'll see a list of online players
- Click "Leaderboard" button to see top players by wins
- Select a player and click "Challenge Selected Player"
- When challenged, a dialog will appear - click "Yes" to accept
- When a game starts, a new window opens with the game board
- Click on any empty cell to make your move
- The game will automatically update and show results
- After game ends, you can:
  * Click "Request Rematch" to play again with the same opponent
  * Click "Back to Lobby" to return to the player list

COMMAND LINE VERSION:
In a client terminal, try these commands:

1. Register a new account:
   > register alice 1234

2. Login:
   > login alice 1234

3. List online players:
   > list

4. Challenge another player (open another client first):
   > challenge bob

5. Accept a challenge (when challenged):
   > accept

6. Make a move (when in a game):
   > move 0 0
   > move 1 1
   (coordinates are 0-2 for rows and columns)

7. View your stats:
   > stats

8. View the board:
   > board

9. Request a rematch (after a game ends):
   > rematch

10. View leaderboard:
   > leaderboard

11. Logout:
   > logout

For all commands, type:
   > help

IMPORTANT NOTES:
- Keep the server running while playing
- You need at least 2 clients to play a game
- The server must be started BEFORE clients connect
- To test with 2 players, open 2 separate terminal windows and run "java Client" in each

=== RUNNING JUNIT TESTS ===

1. Get JUnit (once):  .\download-junit.ps1

2. Compile:  javac -cp ".;lib\*" *.java

3. Run each test:
   java -cp ".;lib\*" org.junit.runner.JUnitCore ProtocolTest
   java -cp ".;lib\*" org.junit.runner.JUnitCore GameSessionTest
   java -cp ".;lib\*" org.junit.runner.JUnitCore GameServerTest
   java -cp ".;lib\*" org.junit.runner.JUnitCore UserManagerTest

If the IDE can't find org.junit, run the download script then reload the window.
